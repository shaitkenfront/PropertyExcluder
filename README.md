# 逆お気に入り for nifty不動産

nifty不動産の中古一戸建てに「候補・保留・却下」の判断、却下理由、一言メモを保存するChrome拡張です。データはChromeのローカルストレージにだけ保存されます。

## MVPでできること

- 検索結果の全物件に「未評価・候補・保留・却下」を表示
- 一覧・詳細画面のどちらからでも状態、却下理由、一言メモを編集
- 却下済みカードを赤枠・半透明で強調
- 却下済み物件をもう一度開く前に、理由とメモを表示して確認
- 検索結果から却下済み物件を一時的に非表示
- 拡張アイコンのポップアップで状態別件数と直近5件を確認

## インストール

1. Chromeで `chrome://extensions/` を開く
2. 右上の「デベロッパーモード」を有効にする
3. 「パッケージ化されていない拡張機能を読み込む」を選ぶ
4. この `PropertyExcluder` フォルダーを指定する
5. nifty不動産の中古一戸建て一覧または詳細ページを再読み込みする

## 使い方

検索結果では、各物件の先頭に「逆お気に入り」の状態行が追加されます。その行をクリックすると編集欄が開きます。

詳細画面では物件タイトル直下に編集パネルが表示されます。「却下」を選んだ場合だけ却下理由タグを選択できます。一言メモは200文字までです。

「未評価に戻す」を押すと、その物件の状態・理由・メモを削除します。

## 保存形式

物件は詳細URLに含まれる32桁の物件番号で識別します。各物件を `propertyExcluder:property:<物件番号>`、表示設定を `propertyExcluder:settings` というキーで `chrome.storage.local` に保存します。

拡張機能を削除すると保存データも削除されます。Chromeアカウント間の同期やクラウド送信は行いません。

## 開発・確認

外部ライブラリやビルド工程はありません。Node.js 20以降があれば、次のコマンドで構文・マニフェスト・共通処理を確認できます。

```powershell
npm test
npm run check
```

## 対応範囲

- 対応: `https://myhome.nifty.com/chuko-ikkodate/<都道府県>/<市区町村>/...` の一覧・詳細ページ
- 対象外: `https://myhome.nifty.com/chuko-ikkodate/<都道府県>/` の条件設定ページ
- MVP対象外: 新築一戸建て、マンション、土地、賃貸

nifty不動産側のHTML構造が大きく変わった場合は、`src/content.js` のカード検出または詳細画面の挿入位置を調整する必要があります。
