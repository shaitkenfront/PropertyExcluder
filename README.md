# 逆お気に入り for nifty不動産

nifty不動産の中古一戸建てと賃貸物件に「候補・保留・却下」の判断、却下理由、一言メモを保存するChrome拡張です。データは通常Chromeのローカルストレージに保存され、必要なときだけJSONファイルへ書き出せます。

## MVPでできること

- 中古一戸建て・賃貸の検索結果と詳細ページに「未評価・候補・保留・却下」を表示
- 一覧・詳細画面のどちらからでも状態、却下理由、一言メモを編集
- 却下済みカードを赤枠・半透明で強調
- 却下済みカードを個別に折り畳み・展開
- 却下済み物件も通常どおり詳細を開ける
- 検索結果から却下済み物件を一時的に非表示
- 一言メモに部屋数などの定型文を追加するショートカット
- 詳細画面の判断パネルを一言メモだけにする印刷モード
- 中古一戸建ての条件設定画面・検索結果の「専有面積・建物面積」に150平米以上を追加
- 中古一戸建ての都道府県条件画面で、市区町村を一括選択し、プリセット条件を設定
- 中古一戸建ての検索結果で、建物面積130㎡未満の物件を「狭さ」の理由で一括却下
- 物件詳細ページの住所横からハザード情報を取得・表示
- 埋め込みGoogleマップの座標を逆ジオコーディングし、住所をGoogleマップへのリンクで表示
- 拡張アイコンのポップアップで状態別件数と直近5件を確認
- ポップアップから判定情報と表示設定をJSONでエクスポート・インポート

## インストール

1. Chromeで `chrome://extensions/` を開く
2. 右上の「デベロッパーモード」を有効にする
3. 「パッケージ化されていない拡張機能を読み込む」を選ぶ
4. この `PropertyExcluder` フォルダーを指定する
5. nifty不動産の中古一戸建てまたは賃貸の一覧・詳細ページを再読み込みする

## 使い方

検索結果では、各物件の先頭に「逆お気に入り」の状態行が追加されます。その行をクリックすると編集欄が開きます。

詳細画面では物件タイトル直下に編集パネルが表示されます。「却下」を選んだ場合だけ却下理由タグを選択できます。一言メモは200文字までです。

「未評価に戻す」を押すと、その物件の状態・理由・メモを削除します。

別のPCへデータを移す場合は、ポップアップの「エクスポート」でJSONファイルを保存します。移行先のPCに同じ拡張機能を読み込み、「インポート」からそのJSONファイルを選択してください。既存データと統合され、同じ物件番号の情報はインポートした内容で上書きされます。

## 保存形式

物件は詳細URLに含まれる32桁の物件番号で識別します。各物件を `propertyExcluder:property:<物件番号>`、表示設定を `propertyExcluder:settings` というキーで `chrome.storage.local` に保存します。

拡張機能を削除すると保存データも削除されます。Chromeアカウント間の同期やクラウド送信は行いません。エクスポートしたJSONファイルは利用者自身で管理してください。

## 開発・確認

外部ライブラリやビルド工程はありません。Node.js 20以降があれば、次のコマンドで構文・マニフェスト・共通処理を確認できます。

```powershell
npm test
npm run check
```

## 対応範囲

- 対応: nifty不動産の中古一戸建て・賃貸、およびハトマークサイトの売一戸建ての一覧・詳細ページ
- 条件プリセット・面積一括却下は中古一戸建て向けです
- MVP対象外: 新築一戸建て、マンション、土地

nifty不動産またはハトマークサイト側のHTML構造が大きく変わった場合は、`src/content.js` のカード検出または詳細画面の挿入位置を調整する必要があります。
